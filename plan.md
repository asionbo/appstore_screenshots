# App Store screenshot generator

- Build a small Node.js CLI project with a JSON config file.
- Use `sharp` to compose PNG screenshots from text and provided images.
- Draw a simple black phone frame around the placed app screenshot area.
- Support ordered text/image pairing by array index.
- Support multi-language output with either user-provided localized text or optional auto-translation.
- Ship an example config, sample assets, and a short README.
